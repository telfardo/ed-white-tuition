all lowercase, .jpg. The names must match or the picture won't appear.

Until a file is here, that slot shows a small striped "add this photo" panel
instead of a broken image, so the page still looks tidy.

Sizing: roughly 1200-1600px on the long edge is plenty. Save as JPEG at about
80% quality so pages stay fast.

Permission: please check that both students (or the six-year-old's parent) are
happy for their photo to appear on a public website before publishing.
